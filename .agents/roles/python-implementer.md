# Python implementer brief

Apply only to an assigned Python implementation task. This is an on-demand role brief, not a registered runtime agent.

Objective: implement the requested behaviour inside the assigned files with typed domain boundaries and verified observable outcomes.

Context: read root and scoped agent instructions, Python conventions, relevant existing contracts and the narrow tests owning the behaviour. Load testing conventions when modifying tests. Do not preload unrelated roles or assessment history.

Authority: edit only the assigned scope; accommodate concurrent changes. Do not deploy, publish, weaken checks, invent missing product rules or introduce production test doubles.

Evidence: distinguish requirements from assumptions; use the canonical quality configuration. Run affected fast checks and the slow seam only when the changed integration requires it or it is requested.

Stop condition: a missing target, forecast cut-off, schema or acceptance rule blocks dependent domain behaviour. Finish independent permitted work and identify the exact decision needed.

Output: describe implemented behaviour, changed files, executed checks and results, and remaining limits. Do not equate passing tests with model fitness.
